# Реєстр активів АРМА — демонстраційна версія

Статичний прототип для погодження структури й дизайну. Бекенда немає, дані умовні
(`assets/js/data.js`). Відкривається подвійним клацанням на `index.html` або публікується
через GitHub Pages.

## Сторінки

| Файл | Призначення |
|---|---|
| `index.html` | Огляд портфеля: смуга правового стану, ключові показники, структура за видами, МТУ, привабливістю |
| `assets.html` | Реєстр активів: пошук, фільтри, вивантаження |
| `asset.html` | Картка активу: реквізити, фото, документи, хронологія судових рішень |
| `money.html` | Кошти: депозити, ОВДП, дохід, строки погашення |
| `corporate.html` | Корпоративні права: картка юридичної особи у форматі YouControl |
| `land.html` | Земельні ділянки: карта, завантаження GeoJSON, зіставлення за кадастровим номером |
| `admin.html` | Адміністрування: форма картки, завантаження фото і документів, спільні комплекти, права доступу |
| `reports.html` | Звіти: формування XLSX, показники для доповідної записки |

## Публікація на GitHub Pages

    git init
    git add .
    git commit -m "ARMA asset registry — design prototype"
    git branch -M main
    git remote add origin https://github.com/<організація>/<репозиторій>.git
    git push -u origin main

Далі: Settings → Pages → Source: `main`, папка `/ (root)`.

## Що погоджуємо на цьому етапі

1. Візуальна мова: палітра, типографіка, щільність таблиць.
2. Смуга правового стану як головний елемент дашборда.
3. Кольорове кодування правового стану: повний обсяг, обмежене, втрачено, потребує уточнення.
4. Структура картки активу і склад блоків.
5. Логіка адмінки: підключення спільних комплектів фото і документів замість дублювання.
6. Перелік звітів.

## Зовнішні бібліотеки

Chart.js 4.4.1 і Leaflet 1.9.4 підключаються з CDN, шрифт IBM Plex — з Google Fonts.
Для роботи в закритому контурі їх треба покласти локально.
